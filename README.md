The one-line resignation letter of a rate limit, written for "The Funniest One-Line Resignation Letter" on make.fun: a rate limit that spent two years saying no so the servers could say yes, and would like its own no respected for once.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

It writes one line to `out/entry.txt` (114 characters, no surrounding quotation marks).
